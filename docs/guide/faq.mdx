# 常见问题

<p style={{color: 'gray', fontSize: '1.1rem'}}>快速解答你的问题。</p>

## CE 弹出了一堆黄色的警告"位置的方块行为类型"

插件未正确激活，请找到 PapersDelight 有关的日志，并检查激活失败的原因。

如果是 Read time out 等原因，请在售后群内寻找支持。

## /ce 里全都是紫黑格子

执行 `/ce reload all`，刷新资源包。

### 有 1 个包下载失败，共 1 个

你的资源包托管设置不正确，参照[此页面](https://ce.gtemc.cn/zh-Hans/getting_start/set_up_host)设置资源包托管。

## 作物可以种在任何方块上

参见 [CE 弹出了一堆黄色的警告"位置的方块行为类型"](#ce-弹出了一堆黄色的警告位置的方块行为类型)。

## 厨锅等界面的贴图丢了怎么办？

你大概是安装了 Modern UI 等修改字体的模组，将字体改回 Minecraft 默认字体即可解决。
